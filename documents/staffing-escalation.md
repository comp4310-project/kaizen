# Purpose

Short staffing is escalated early so that it does not lead to unsafe care.

# Planning each shift

The charge nurse compares staff on duty with patient needs at the start of each shift using the unit's staffing tool.

If staffing is below the planned level, the charge nurse asks the staffing office for a nurse from the float pool before the shift starts.

# Escalation

If no replacement is found, the charge nurse informs the manager or on-call manager, who decides on actions such as moving staff between units or delaying non-urgent admissions.

During short-staffed shifts the team agrees at the start of the shift which tasks will be prioritised and which patients need closer watching.

# Reporting

Staff report shifts where short staffing affected patient care in the incident system, so patterns can be seen across units.

# Measures

The hospital tracks shifts below planned staffing by unit and the incidents reported on those shifts.
